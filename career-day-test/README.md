# Hope Creator 모바일 UI 테스트

GitHub Pages용 정적 테스트본입니다.

- 소개서 작성, 필수 입력 후 그림판 해금, 현재 메이트 참고, 캐릭터의 섬 이동, 카드 크게 보기, PNG 저장을 테스트합니다.
- 카드와 초안은 브라우저에 저장합니다. 데이터는 서버에 전송하지 않습니다.
- 반응은 현재 기기의 캐릭터로 표시하는 시뮬레이션입니다. 다른 기기에 전달되지 않습니다.
- 여러 사람의 카드와 반응 공유 기능은 원본의 서버/API를 별도 배포한 후 연결해야 합니다.
- 예시 소개는 모두 허구이며 실제 참여자 데이터, 인증정보, 회사 배포 설정을 포함하지 않습니다.

## 편집

화면 구조는 index.html, 스타일은 studio/island.css, 글자 수·움직임 설정은 studio/ui-config.js, 화면 동작은 studio/app.js에서 수정합니다.

## GitHub Pages

이 폴더의 파일만 저장소 루트에 업로드하고 Pages 게시 소스를 main 브랜치의 /로 설정합니다. .nojekyll 파일을 유지합니다. 저장소 하위 경로로 배포해도 작동합니다.
